# Состояние торгов вычисляется из времени, worker только финализирует

Открыт ли лот для ставок и какова текущая цена голландского аукциона, определяется из сохранённых моментов времени и правил (`packages/domain`), а не из статуса, который выставляет фоновая задача. Worker (BullMQ) лишь финализирует уже завершившиеся торги: создаёт сделку, начисление, уведомления, перевыставление. Так правила торгов корректны при любой задержке или сбое очереди: ставка после окончания отклоняется, даже если финализация ещё не прошла.

## Consequences

- Финализация обязана быть идемпотентной; помимо отложенных задач worker периодически «подметает» завершённые, но не финализированные лоты.
- Продление торгов меняет сохранённое время окончания в той же транзакции, что и ставка; гонки ставок решаются блокировкой строки лота (`SELECT … FOR UPDATE`).
