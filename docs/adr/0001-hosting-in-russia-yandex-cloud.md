# Хостинг только в РФ, в Yandex Cloud

Площадка хранит персональные данные граждан РФ (телефоны, имена, переписку), поэтому по 152-ФЗ все окружения с данными пользователей размещаются на серверах в РФ. Выбран Yandex Cloud: Managed PostgreSQL, Object Storage + CDN, VM для приложения. Vercel + Neon рассматривались для разработки и отклонены: переезд потом стоил бы переделки фоновых задач и real-time, а данные за рубежом недопустимы даже на закрытой бете.

## Consequences

- Разработка идёт локально в docker compose; первое облачное окружение — сразу в Yandex Cloud, конфигурация «Старт» (одна VM, один хост PostgreSQL, Redis в Docker на VM). Реплика БД и Managed Valkey включаются по мере роста без изменений кода.
- Хранилище файлов используется через S3-совместимый интерфейс (локально — MinIO).
