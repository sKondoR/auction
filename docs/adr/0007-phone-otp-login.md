# Вход по телефону через SMS-код, Better Auth

Основной способ входа — номер телефона и одноразовый SMS-код (без пароля); подтверждённый телефон одновременно служит верификацией пользователя. Реализация — Better Auth (плагин phone-number, сессии в PostgreSQL, роли через плагин admin), SMS-провайдер — за адаптером (локально коды пишутся в консоль).

## Consequences

- SMS — главная переменная статья расходов: сессии долгие, отправка кодов ограничивается по частоте на номер и IP.
- Буквенное имя отправителя SMS нужно зарегистрировать заранее, до запуска.
