# Правила торгов — в отдельном пакете без зависимостей от фреймворка

Монорепозиторий на pnpm workspaces: `apps/web` (Next.js), `apps/worker` (BullMQ), `packages/db` (Drizzle), `packages/domain`. Все правила торгов — шаги ставок, автоставки, продление, блиц-цена, голландское снижение, переходы статусов сделки, расчёт комиссии — живут в `packages/domain` как чистые функции над данными и покрываются тестами Vitest. Их используют и web, и worker, и будущий real-time сервис живого аукциона; дублирование правил между ними недопустимо.

Drizzle выбран вместо Prisma ради прямого контроля над SQL (блокировки строк, полнотекстовый поиск PostgreSQL) и обычных SQL-миграций.
