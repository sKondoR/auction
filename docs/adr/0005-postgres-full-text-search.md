# Поиск на PostgreSQL на старте

Поиск по лотам (включая прошедшие торги) реализуется полнотекстовым поиском PostgreSQL с русской морфологией, за интерфейсом-абстракцией. Отдельный движок (Meilisearch/OpenSearch) отложен: он добавляет инфраструктуру и синхронизацию индекса, а на старте объёмы невелики. Переход — когда лотов станет больше ~100 тыс. или понадобятся исправление опечаток и фасеты.
