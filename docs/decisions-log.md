## Раунд 1. Корневые вопросы

| № | Вопрос | Решение |
|---|---|---|
| Q1 | Что строим? | C2C-площадка торгов в духе meshok.ru / auction.ru + живые торги как ru.bidspirit.com. Любой пользователь — и продавец, и покупатель. Четыре формата: фиксированная цена (до 60 дней, затем перевыставление), английский аукцион (с 1 ₽, 1–21 день, блиц-цена, которую продавец может снижать), голландский аукцион (снижение цены от максимальной, шаг ≥ 5%, каждые 3/5/7/10 дней, до 90 дней), живой аукцион (каталог, место осмотра, видеотрансляция, ставки по лотам по очереди, сессия без ограничения по времени). Под каждым лотом — «Связаться с продавцом» (публичные и приватные вопросы, без передачи контактов). Личный кабинет. Оплата напрямую продавцу, комиссия площадки 1%. «Продать администрации». Рекомендации с заделом под платное продвижение. Поиск по прошедшим и предстоящим торгам |
| Q2 | Зачем и для кого? | Реальный запуск (ответ дан в раунде 2) |
| Q3 | Формат аукциона | Все четыре формата (см. Q1) |
| Q4 | Платформа | Адаптивный веб (ответ дан в раунде 2, Q11) |
| Q5 | Ограничения: стек, сроки, команда | Стек: pnpm, Vite, Next.js (уточнено в раунде 2, Q11a) |

## Раунд 3. Сценарии и инфраструктура

| № | Вопрос | Решение |
|---|---|---|
| Q1 | Ниша и категории | Вертикаль «коллекционирование и антиквариат»; дерево категорий в админке; атрибуты по категориям и фильтры по ним |
| Q2 | Команда и сроки | Пользователь + Claude, итерациями; фиксированной даты нет |
| Q3 | Сделка после продажи | Статусы: продано → ждёт оплаты → оплачено → отправлено → получено → отзывы; 3 дня на связь, 7 на оплату; «Неоплата» после 7 дней — штрафной отзыв и сторно комиссии |
| Q4 | Доставка и местоположение | Город обязателен; способы доставки галочками, стоимость текстом; фильтр по городу; без интеграций со СДЭК/Почтой |
| Q5 | Оплата счетов за комиссию | Интеграцию с оплатой пока откладываем |

| Q7 | Уведомления | Этап 1 — на сайте + email; этап 2 — Telegram-бот; пользователь настраивает события и каналы |
| Q8 | Инфраструктура | Yandex Cloud (Managed PostgreSQL, Object Storage + CDN, Docker); до 20 фото на лот. ~~На время разработки — Vercel + Neon~~ (пересмотрено в раунде 4) |
| Q9 | Фоновые задачи | Отдельный worker с BullMQ в том же монорепозитории, доменная логика в общем пакете |
| Q10 | Real-time на этапе 1 | SSE через Redis pub/sub; WebSocket — к этапу 3 |
| Q11 | Поиск | Полнотекстовый поиск PostgreSQL за абстракцией; Meilisearch — при росте |
| Q12 | «Продать администрации» | Этап 1; форма + очередь заявок; статусы новая → на рассмотрении → предложение → принята/отклонена; выкупленное продаётся от служебного аккаунта |
| Q13 | Админка | Раздел `/admin` в Next.js; 3 роли: администратор, модератор, оценщик |

### Дополнительно: оценка стоимости Yandex Cloud

По прайсу на 2026 год: конфигурация «Старт» (VM + 1 хост PostgreSQL + Redis в Docker + Object Storage + CDN) — **≈ 7–8 тыс. ₽/мес**; «Рост» (VM 4 vCPU, PostgreSQL с репликой, Managed Valkey, ~500 ГБ фото, ~1,5 ТБ CDN) — **≈ 25 тыс. ₽/мес**. Вне расчёта: SMS (~3–5 ₽ за сообщение), видео для живого аукциона, балансировщик.

## Раунд 5. Окружения, деплой, живой аукцион

| № | Вопрос | Решение |
|---|---|---|
| Q1 | Конфигурация продакшна | Сначала работаем локально, затем переходим на платную инфраструктуру (конфигурация «Старт») |
| Q2 | Окружения | Локально — docker compose (Postgres, Redis, MinIO, SMS-коды в консоль); staging до запуска — на прод-VM с отдельной базой; после запуска — отдельная VM |
| Q3 | Деплой | (a) GitHub Actions → Yandex Container Registry → `docker compose` на VM по SSH; миграции отдельным шагом; Caddy для домена и HTTPS |
| Q4 | Название и домен | Рабочее имя `auction`; имя отправителя SMS регистрировать заранее |
| Q5 | Комиссия: граничные случаи | Без минимума и потолка; размещение бесплатное; комиссия с фактической цены сделки, за каждую единицу |
| Q6 | Страница продавца | Да, на этапе 1, с подпиской на продавца |
| Q7 | Живой аукцион: видео | (b) Сервис стриминга (Yandex Cloud Video / Kinescope), low-latency HLS; ставки и текущий лот — по WebSocket; истина — состояние торгов |
| Q8 | Живой аукцион: механика | Каталог за 3+ дня; заочные ставки; регистрация на торги в один клик без залога; шаг из общей сетки; закрытие кнопкой «Продано» после отсчёта; старт с 1 ₽ или цена продавца; непроданное — перевыставить в другом формате |
| Q9 | Кто проводит живой аукцион | Только по одобренной заявке и при минимальном рейтинге; до 300 лотов в каталоге |
| Q10 | Рекомендации и продвижение | Этап 1: похожие лоты, «продавец также продаёт», «вы недавно смотрели»; для продвижения — только поле и сортировка |
