# PRD: площадка онлайн-торгов `auction`

> Рабочее название — `auction`, будет заменено. Термины — см. [CONTEXT.md](../CONTEXT.md). Ключевые технические решения — см. [docs/adr/](./adr/).

## 1. Суть продукта

C2C-площадка для торгов предметами коллекционирования и антиквариата в РФ. Любой **Пользователь** может выступать и **Продавцом** (по своим лотам), и **Покупателем** (по чужим).

Площадка **не участвует в расчётах**: покупатель переводит деньги продавцу напрямую. Доход площадки — **комиссия 1%** с каждой продажи (в будущем — платное продвижение лотов).

Ориентиры: meshok.ru, auction.ru (форматы 1–2), ru.bidspirit.com (живой аукцион).

## 2. Этапы

Модель данных с первого дня проектируется под все четыре формата торгов.

| Этап | Состав |
|---|---|
| **1** | Фиксированная цена, английский аукцион, переписка, вопросы под лотом, личный кабинет, сделки и отзывы, комиссия и счета, поиск, страница продавца, подписки на продавца, сохранённые поиски, рекомендации, «Продать администрации», админка, уведомления (на сайте + email) |
| **2** | Голландский аукцион, Telegram-бот уведомлений |
| **3** | Живой аукцион (видеотрансляция, торги в реальном времени) |
| Позже | Эквайринг (ЮKassa) для оплаты счетов и платное продвижение, VK ID / Яндекс ID, интеграции со службами доставки, персональные рекомендации |

## 3. Пользователи и доступ

- Регистрация и вход — по номеру телефона с одноразовым SMS-кодом. Email — необязателен, используется для уведомлений.
- Подтверждённый телефон обязателен для ставок, покупок и продажи. Паспорт не требуется.
- **Новички** (без отзывов) ограничены по числу одновременных ставок и активных лотов; лимиты настраиваются в админке.
- Роли администрации:
  - **Администратор** — всё, включая категории, сетку шагов, лимиты, счета, настройки.
  - **Модератор** — лоты, жалобы, переписка, предупреждения и блокировки.
  - **Оценщик** — заявки «Продать администрации».
- **Удаление аккаунта** (152-ФЗ): персональные данные обезличиваются (имя → «Пользователь удалён», телефон и email стираются). Лоты, ставки, сделки и отзывы остаются в истории без привязки к человеку.

## 4. Лот

- Категория из дерева категорий (редактируется в админке). У категории — набор **атрибутов** (например, для монет: год, номинал, металл, сохранность), по которым работают фильтры.
- Название, описание, до 20 фото (автоматически сжимаются, генерируются превью), город (обязательно), способы доставки (галочки: почта, СДЭК, самовывоз, …) и стоимость доставки текстом.
- Лоты публикуются **без премодерации**; модератор может снять лот постфактум.
- Контактные данные (телефоны, email, ссылки, мессенджеры) в описаниях автоматически маскируются.
- **Правила изменения после первой ставки:**
  - описание можно только **дополнять** — дополнение показывается отдельным блоком с датой;
  - цену, формат и срок менять нельзя (исключение — снижение блиц-цены);
  - продавец может **досрочно снять** лот — участники получают уведомление, на странице продавца растёт счётчик снятых с торгов;
  - продавец может **отменить чужую ставку** с указанием причины;
  - покупатель **не может отозвать** свою ставку.
- **Автоперевыставление:** опция при создании лота «перевыставить автоматически до 3 раз», по умолчанию выключена. Без неё лот без продажи попадает в «Завершённые без продажи», откуда перевыставляется одной кнопкой, в том числе в другом формате.

## 5. Форматы торгов

### 5.1 Фиксированная цена (этап 1)

- Срок размещения — до 60 дней. После — лот снимается; требуется перевыставление (чтобы отсеивать неактуальные предложения).
- За 3 дня до окончания — напоминание продавцу. Перевыставление вручную, в том числе массово.
- Количество может быть больше одного.
- Опция продавца «**Предложить свою цену**»: покупатель предлагает цену, продавец принимает или отклоняет.

### 5.2 Английский аукцион (этап 1)

- Старт с любой цены от 1 ₽. Срок — от 1 до 21 дня.
- **Шаг ставки** — по сетке (редактируется в админке), по умолчанию:

  | Текущая цена | Шаг |
  |---|---|
  | до 100 ₽ | 5 ₽ |
  | 100–1 000 ₽ | 10 ₽ |
  | 1 000–5 000 ₽ | 50 ₽ |
  | 5 000–20 000 ₽ | 100 ₽ |
  | 20 000–100 000 ₽ | 500 ₽ |
  | от 100 000 ₽ | 1 000 ₽ |

- **Автоставка:** покупатель указывает максимум, система повышает его ставку на минимальный шаг при перебивании, пока не упрётся в максимум.
- **Антиснайпинг:** ставка в последние 5 минут продлевает окончание торгов на 5 минут от момента ставки.
- **Блиц-цена** (необязательна): покупка «прямо сейчас» по фиксированной цене.
  - Доступна, пока текущая ставка ниже блиц-цены.
  - Продавец может только **снижать** её в ходе торгов, но не ниже «текущая ставка + шаг».
- Резервной (скрытой минимальной) цены нет.
- Торги без ставок к окончанию — лот не продан (см. автоперевыставление).

### 5.3 Голландский аукцион (этап 2)

- Продавец задаёт стартовую (максимальную) цену, **минимальную цену**, интервал снижения — 3, 5, 7 или 10 дней, и шаг снижения — **не менее 5%**.
- Процент считается **от стартовой цены** (линейное снижение).
- Срок — до 90 дней. Достигнув минимальной цены, цена стоит на ней до конца срока.
- Покупает первый, кто нажал «Купить» по текущей цене.
- Продавец может снять лот, пока его не купили.

### 5.4 Живой аукцион (этап 3)

- Проводят только продавцы, чья **заявка одобрена администрацией** и у кого рейтинг не ниже минимального.
- **Торговая сессия**: продавец объявляет дату и время, публикует каталог (до 300 лотов) **не позднее чем за 3 дня**. Указывает место, где предметы можно осмотреть лично, либо что такого места нет.
- Участие — после **регистрации на торги** в один клик (без залога).
- До начала можно оставить **заочную ставку** («готов до X ₽»); во время торгов система торгуется за участника.
- В назначенное время продавец ведёт видеотрансляцию, переключает лоты по порядку; ставки принимаются на текущий лот. Шаг — из общей сетки. Стартовая цена — 1 ₽ или заданная продавцом для лота.
- Лот закрывает продавец кнопкой «Продано» после обратного отсчёта (5–10 секунд), видимого всем участникам.
- Длительность сессии не ограничена.
- **Истиной считается состояние торгов, а не видео**: статус лота и ставки приходят участникам в реальном времени независимо от задержки трансляции.
- Непроданный лот можно перевыставить в другом формате.

## 6. Общение

- **Вопросы под лотом**: покупатель может задать вопрос публично или поставить галочку «приватный вопрос». Ответ на публичный вопрос публичен и показывается под лотом в блоке «Вопросы и ответы». Приватный вопрос нельзя сделать публичным.
- **Беседа**: одна на пару «покупатель ↔ продавец»; каждое сообщение привязано к лоту, о котором идёт речь. Кнопка «Связаться с продавцом» есть под каждым лотом во всех форматах. После продажи обсуждение оплаты и доставки идёт в той же беседе, с карточкой сделки.
- Передача персональных и контактных данных запрещена: автофильтр маскирует контакты, есть кнопка «Пожаловаться».

## 7. Сделка и репутация

- Выигрыш (или покупка) **обязывает** выкупить лот.
- Статусы **сделки**: продано → ждёт оплаты → оплачено (отмечает продавец) → отправлено → получено (отмечает покупатель) → отзывы.
- Сроки: 3 дня на связь, 7 дней на оплату.
- **«Покупатель не оплатил»** — доступно продавцу после 7 дней: покупатель получает штрафной отзыв, комиссия по сделке сторнируется, продавец может предложить лот следующему участнику или перевыставить.
- **«Товар не получен»** — зеркальная кнопка для покупателя, влияет на рейтинг продавца.
- **Отзывы**: после сделки обе стороны оставляют отзыв (положительный / нейтральный / отрицательный). Накопление X штрафных отзывов ведёт к блокировке (порог — в админке).
- **Арбитража по деньгам нет** (площадка не участвует в расчётах) — это прямо указывается в правилах. Модерация реагирует на жалобы о нарушении правил: предупреждение, блокировка.

## 8. Комиссия и счета

- **1%** от фактической цены сделки (при количестве больше одного — за каждую единицу; при «Предложить свою цену» — от согласованной цены). Без минимума и без потолка. Размещение лотов бесплатное.
- Каждое начисление записывается в **книгу начислений** продавца; при «Покупатель не оплатил» начисление сторнируется.
- **Счёт** формируется 1-го числа за прошлый месяц, если сумма ≥ 100 ₽; меньшая сумма переносится на следующий месяц.
- На оплату — 10 дней. После просрочки продавцу **блокируется выставление новых лотов**; активные торги доживают до конца.
- До подключения эквайринга: продавец видит счёт и реквизиты в кабинете, администратор отмечает оплату вручную. Позже — кнопка «Оплатить» через ЮKassa на тот же счёт.

## 9. Личный кабинет

- Как покупатель: избранные лоты, лоты с моими ставками (лидирую / перебита), выигранные и купленные, сделки, сохранённые поиски, подписки на продавцов, недавно просмотренные.
- Как продавец: мои лоты по статусам (активные, завершённые с продажей, завершённые без продажи, скоро истекают), сделки, счета и книга начислений, заявки «Продать администрации».
- Беседы, уведомления, настройки уведомлений (что и в какой канал).

## 10. Страница продавца

Все активные лоты продавца, отзывы и рейтинг, дата регистрации, счётчик досрочно снятых лотов. Кнопка «Подписаться на продавца» — уведомления о его новых лотах.

## 11. Поиск, подписки, рекомендации

- **Поиск** по названию и описанию с учётом русской морфологии, по **предстоящим, идущим и прошедшим** торгам. Фильтры: категория, атрибуты категории, формат, цена, город, статус.
- **Сохранённый поиск**: запрос и фильтры сохраняются, пользователь получает уведомления о новых совпадениях.
- **Рекомендации** на странице лота: похожие лоты (та же категория, близкая цена), «Продавец также продаёт», «Вы недавно смотрели».
- **Платное продвижение** — пока только заложено в модели данных (срок продвижения лота, учитываемый в сортировке), без интерфейса и оплаты.

## 12. «Продать администрации»

(Название будет изменено.) Продавец отправляет предмет на оценку для выкупа площадкой.

- Обязательные поля: желаемая цена, размер, описание, фото.
- Статусы заявки: новая → на рассмотрении → предложение (оценщик называет цену) → принята / отклонена.
- Общение по заявке — в беседе с администрацией.
- Выкупленные предметы продаются от **служебного аккаунта** площадки как обычные лоты.

## 13. Уведомления

События: перебили ставку, торги завершены (выиграл / продал / не продано), новое сообщение, ответ на вопрос, изменение статуса сделки, скоро истекает размещение, выставлен счёт / просрочен, новые лоты подписки или сохранённого поиска, скорое начало живого аукциона.

Каналы: на сайте (колокольчик) и email — этап 1; Telegram-бот — этап 2. Пользователь настраивает события и каналы.

## 14. Правовые рамки

- Работа только в РФ, в рублях. Оператор площадки — ИП или ООО.
- Персональные данные хранятся на серверах в РФ (152-ФЗ) — с первого дня, включая тестовые окружения.
- Оферта и правила площадки, включая список запрещённых категорий товаров и отсутствие арбитража по расчётам.

## 15. Технический обзор

- **Стек:** TypeScript, pnpm workspaces, Next.js, Vitest, Drizzle, PostgreSQL, Redis, BullMQ, Better Auth, Tailwind + shadcn/ui.
- **Монорепозиторий:**
  ```
  apps/web          — Next.js: сайт, /admin, API, SSE
  apps/worker       — фоновые задачи (BullMQ): финализация торгов, голландское снижение,
                      перевыставление, счета, уведомления, сохранённые поиски
  packages/domain   — правила торгов на чистом TS, без зависимостей от фреймворка
  packages/db       — схема Drizzle и миграции
  ```
- Суммы хранятся в копейках (целые числа).
- Состояние торгов (открыт ли лот для ставок) вычисляется из времени; worker финализирует завершённые торги — см. [ADR 0003](./adr/0003-time-derived-auction-state.md).
- Реальное время: SSE на этапе 1, WebSocket на этапе 3.
- **Окружения:** локально — docker compose (Postgres, Redis, MinIO, SMS-коды в консоль). Перед запуском — Yandex Cloud, конфигурация «Старт» (~7 тыс. ₽/мес): VM (web + worker + Redis в Docker, Caddy), Managed PostgreSQL (1 хост), Object Storage + CDN. Staging до запуска — на той же VM с отдельной базой.
- **Деплой:** GitHub Actions → Docker-образы → Yandex Container Registry → `docker compose` на VM по SSH; миграции — отдельным шагом до переключения.

## 16. Открытые вопросы

- Название площадки и домен; буквенное имя отправителя SMS (регистрировать заранее).
- Конкретные значения лимитов для новичков, порог штрафных отзывов для блокировки, минимальный рейтинг для живого аукциона.
- Список запрещённых категорий.
- Выбор сервиса видеостриминга для живого аукциона (Yandex Cloud Video / Kinescope) — на этапе 3.
- SMS-провайдер (SMS.ru / SMSC) и стоимость SMS — основная переменная статья расходов.
